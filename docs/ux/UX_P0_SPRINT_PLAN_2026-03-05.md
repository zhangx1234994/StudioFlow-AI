## 2) 任务拆分（前端/后端/测试）

## UX-P0-01 首屏产出预期卡
- 前端：
  - 新增 `OutcomePreviewCard` 组件（输入：工具类型、目标张数/时长、预计耗时、交付说明）
  - 接入页面：商品棚拍、模特精修、多角度、15秒短片、讲解视频
- 后端：
  - 若当前任务缺少“预计耗时”，由接口增加 `estimated_duration_hint`
- 测试：
  - Playwright 断言首屏可见“产出数量/预计耗时/交付内容”

## UX-P0-02 任务优先队列
- 前端：
  - 任务区改为 `PriorityQueue + Recent3 + ViewAll`
  - 队列规则：失败/待确认/执行中（按更新时间降序）
- 后端：
  - 提供排序字段：`risk_level`、`next_action`
- 测试：
  - API 与前端排序一致性断言；回归“最近任务定位耗时”

## UX-P0-06 单主 CTA + 状态统一
- 前端：
  - 每步主操作按钮唯一（其余动作收进“更多操作”）
  - 状态统一：提交中/执行中/成功/失败；禁用态带原因提示
- 后端：
  - 错误码归一：`INVALID_INPUT / NETWORK_TIMEOUT / UPSTREAM_FAILED`
- 测试：
  - Playwright 覆盖按钮状态流转和错误提示可见性

## UX-P0-07 继续上次任务入口
- 前端：
  - 首页、资产页、工具页顶部新增“继续上次任务”卡片
  - 无任务时显示清晰空态引导
- 后端：
  - 新增或复用最近任务接口（按用户维度）
- 测试：
  - 登录后 10 秒内可一键回到最近任务工作台

## UX-P0-03 破图兜底
- 前端：
  - 图片组件统一 `onError` 回退品牌兜底图
  - 占位图改低对比中性样式（禁止红色故障感）
- 后端：
  - 样片 URL 空值时返回兜底资源 URL
- 测试：
  - 构造坏链路 URL，断言无破图露出

## UX-P0-05 积分概览优先
- 前端：
  - 首屏改为余额卡 + 可用天数 + 7日趋势，流水折叠
- 后端：
  - 增加 `available_days_estimate` 与 `weekly_usage_summary`
- 测试：
  - 积分页首屏不出现超长表；概览字段完整

## UX-P0-04 用户管理异常优先
- 前端：
  - 默认 Tab：异常账号/待处理账号
  - 高风险操作二次确认
- 后端：
  - 用户列表支持 `view=abnormal` 快速过滤
- 测试：
  - 客服场景 60 秒定位异常账号
