## 3. 页面级改造优先级（P0/P1/P2）

## S1 15秒短片工坊
- P0：首屏增加“产出预期卡”（示例脚本/示例成片）。
- P1：创建区与历史任务区分屏（默认只看创建）。
- P2：高级设置默认折叠并加“推荐模板一键填充”。

## S2 多角度展品工坊
- P0：创建页直接强化“机位体验入口”视觉（不是录单页）。
- P1：任务区增加“最近继续机位任务”置顶。
- P2：进度文案改成动作语（下一步做什么）。

## S3 商品棚拍工坊
- P0：长表默认折叠，首屏只显示“我最近3单”。
- P1：任务行增加优先级标签（卡住/待确认/可交付）。
- P2：关键字段分组（必填三项优先，其他后置）。

## S4 资产中台
- P0：彻底清除破图/占位红块（稳定兜底图策略）。
- P1：默认 tab 固定“我的在途任务”并突出“继续上次”。
- P2：高级筛选下沉到二级交互，先看重点再筛选。

## S5 转化讲解视频工坊
- P0：脚本预览前置为主区（创建不是主角，内容才是主角）。
- P1：任务区同 S3 做优先级分层。
- P2：增加预计耗时与关键里程碑提示。

## S6 模特精修工坊
- P0：批次卡按状态分组（待确认/执行中/可导出）。
- P1：每卡只保留一个主动作按钮，减少并列操作。
- P2：新增“我刚创建的批次”快捷锚点。

## S7 首页
- P0：样片墙稳定可视（禁止破图进入首页）。
- P1：首页主叙事固定为“样片吸引 -> 一键开工 -> 继续任务”。
- P2：运营模块精简成两层，不做同权重堆叠。

## S8 积分中心
- P0：默认显示概览卡，不默认展开超长流水。
- P1：增加“余额可用天数/近7天消耗趋势”。
- P2：流水支持时间与类型快速筛选。

## S9 用户管理
- P0：默认展示“异常账号/待处理账号”而非全量长表。
- P1：操作按钮分层（高风险操作二次确认）。
- P2：支持批量操作与角色筛选。

## 4. 跨页面共性 P0（立即执行）

1. 任何页面首屏必须有“结果预期”而不只是字段。  
2. 历史任务不能默认全量展开压住主流程。  
3. 任务必须可一眼区分优先级（卡住/待确认/可交付）。  
4. 破图与占位图禁止进入可见主界面。
