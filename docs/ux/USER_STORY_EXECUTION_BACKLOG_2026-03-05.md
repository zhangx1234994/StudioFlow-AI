## 6. 验收脚本（必须执行）

1. 新手运营路径（U1）：30 秒内完成“创建并进入执行态”。
2. 视频编导路径（U3）：60 秒内进入脚本确认并提交执行。
3. 交付经理路径（U7）：10 秒内定位“最该处理批次”。
4. 客服路径（U8）：60 秒内定位异常账号并进入详情。
5. 财务路径（U9）：首页级看完积分结论后再钻取明细。
