# 工具总览与流程差异

本页用于统一解释 5 个工具的输入、核心步骤与输出差异。所有页面/接口/提示词必须以此为准。

## 1) intro-video 转化讲解视频工坊
**输入**：产品图、平台、卖点、时长、风格
**流程**：创建 → VL 产 3 套脚本 → 选/改脚本 → 分镜 → 视频候选矩阵 → 选片
**输出**：多段候选视频 + 可追溯脚本

## 2) product-image 商品棚拍出图工坊
**输入**：产品图、风格参考、出图数量、拍摄意图
**流程**：创建 → 拍摄方案（镜头清单） → 批量试拍 → 选片分享
**输出**：组图候选 + 已选成片

## 3) model-retouch 模特人像精修工坊
**输入**：主素材组图（必填）、风格参考（可选）、替换模特图（可选）
**流程**：创建批次（自动进入批量工作台）→ 身份确认（上传也需确认）→ 批量并行精修（逐张回填）→ 结果审核与导出
**输出**：整组精修结果、身份一致性锚点、单张重跑能力

## 4) quick-video-15s 15 秒场景短片工坊
**输入**：产品图/场景图、平台、风格
**流程**：创建 → 15 秒节奏方案 → 一键生成候选 → 选片
**输出**：15 秒候选视频

## 5) multi-angle-camera 多角度展品工坊
**输入**：单张产品图、机位参数
**流程**：上传 → 机位控制（yaw/pitch/distance/focal） → 生成当前角度 → 结果网格
**输出**：多角度图集

---

## 关键 UX 规则
- 图片类工具不得出现视频字段（如时长）。
- 视频类工具不得出现图片批量/角度字段。
- 每步只有一个主 CTA；非主操作收起为“高级操作”。

## 全局运营能力（跨工具）
- 样片墙：已分享素材公开展示，可一键“拍同款”创建任务。
- 积分中心：查看余额与流水，当前版本由管理员手动调整积分（充值通道预留）。
- 用户管理：管理员可创建/禁用账号、调整角色。
- 账号体系：支持本地注册；登录具备账号锁定与 IP 限流风控。
- 计费：图片按成功张数计费，视频按成功候选数计费；分享样片可获得积分奖励。
- 权限：member 仅可见本人任务，operator/admin 可查看全量任务。
