# 04 运营与内容结构（P1 冻结版）

## 1) 样片墙定位（公开展示区）
- 展示维度：主图套图 / 场景套图 / 模特精修 / 多角度图 / 15 秒短片。
- 每个样片卡必须有：行业标签、产出工具、风格标签、转化入口。
- 样片与私有素材严格隔离，私有素材默认永不公开。

## 2) 拍同款落地流程（冻结）
1. 用户在首页样片墙点击“拍同款”。
2. 进入“同款向导弹层”：自动带入样片的工具类型、风格模板、推荐参数。
3. 用户仅补充最小信息（产品图/目标平台/目标张数或视频类型）。
4. 系统直接创建同款项目并跳转对应工作台 Step1。
5. 完成生成后可选择“发布到我的样片墙”（奖励积分）或仅私有保存。

约束：
- 同款向导必须单主 CTA：“立即拍同款”。
- 样片引用采用模板引用，不复制原项目私有资源。
- 同款链路全程可追踪（记录来源样片 `source_showcase_asset_id`）。

## 3) 套图销售区（商业化）
- 套图包：主图包 / 场景包 / 人像包 / 多角度包 / 视频包。
- 卡片字段：价格、交付 SLA、包含张数/时长、适用平台、推荐行业。
- 操作按钮：`立即开拍`（主） + `查看案例`（次）。

## 4) 首页首屏转化结构
- Hero：价值主张 + 两个高价值入口（立即开拍、查看样片）。
- 样片墙：主打案例（大卡）+ 热门案例（网格）+ 拍同款按钮。
- 商业区：套餐包 + 近期热销信号位（帮助选择）。
- 工具区：按业务价值排序的 5 工坊入口。

## 5) 运营指标（用于后续埋点）
- 样片曝光 -> 拍同款点击率（CTR）
- 拍同款点击 -> 创建成功率
- 创建成功 -> 首次出片时长
- 出片 -> 分享率 / 再次下单率
