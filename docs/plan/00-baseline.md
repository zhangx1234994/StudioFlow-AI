# 00 统一基线与术语

## 目标
- 统一产品定位与边界，避免工具间语义冲突
- 为后续 IA / 交互 / 文案建立统一口径

## 产品定位（一句话）
AI摄影棚：面向电商团队的一站式在线摄影生产线，帮你“规划 → 生成 → 精修 → 出片”。

## 产品愿景与边界
### 做什么
- 提供图像与视频的电商生产能力（主图/场景/模特/多角度/短视频）
- 提供“方案化生成”与“批量交付”
- 提供企业可运营的样片墙与套餐入口

### 不做什么
- 不做电商上架/店铺装修/投放管理（只聚焦视觉生产）
- 不做大型视频剪辑/复杂后期（交付前视觉素材为主）

## 目标用户画像（首发）
- 代运营团队：高频出图出片、交付压力大、需要模板化与批量能力
- 品牌电商：追求统一风格与资产沉淀
- 外包/摄影工作室：希望扩展产能与交付速度

## 典型任务清单
- 新品上架（主图套图 + 详情场景）
- 爆款优化（主图重拍/对比图）
- 模特换季/换脸/动作精修
- 产品多角度展示
- 15秒场景短片

## 成功指标（衡量标准）
- 转化：注册 → 首单转化率
- 效率：首单从创建到交付的平均时长
- 质量：人工通过率 / 返工率
- 成本：单图/单视频成本与毛利
- 留存：7日/30日复访

## 术语表（统一口径）
### 方案相关
- **拍摄方案**：用于“商品棚拍出图工坊”的镜头规划
- **精修方案**：用于“模特精修工坊”的局部/一致性修正规划
- **执行方案**：面向模型的可执行指令集合（用户不直接修改）

### 任务结构
- **批次**：一次上传或一次创建产生的多任务集合
- **单图任务**：批次内的单张图片精修任务

### 结果与流程
- **试拍**：候选图生成阶段
- **成片**：被用户选中并标记为交付的结果
- **身份确认**：替换模特流程中的“锚点确认”阶段

## 命名规范（文案约束）
- 页面中不出现“prompt/提示词”等术语
- 对用户仅显示“方案/偏好/指令”
