# 09 转化讲解视频工坊

## 流程
- 脚本选择 → 分镜 → 视频矩阵 → 选片

## 脚本
- 3 套候选脚本
- 用户必须确认一套

## 分镜
- 分镜逐镜确认
- 未确认不可生成视频

## 生成
- 视频矩阵实时进度
- 禁字幕 / 禁水印

## 主 CTA
- Step1：生成脚本候选
- Step2：确认脚本并进入分镜
- Step3：开始生成视频
- Step4：完成选片

## 状态与等待
- 分镜确认：未确认不可生成
- 生成中：矩阵进度 + 单格重试

## 异常与边界
- 未选择脚本：阻止生成
- 分镜未确认：阻止视频生成

## 文案模板（关键节点）
- 成功：脚本已确认，进入分镜
- 失败：分镜生成失败，请重试
- 提示：未确认分镜无法生成视频

## 状态规范（空态/加载/失败）
- 空态：暂无脚本，请先生成脚本候选
- 加载：分镜生成中，预计 1-2 分钟
- 失败：分镜生成失败，请重试
