# 15 规划期交付物

## 必交付
- 产品蓝图（总流程 + 工具差异）
- 费用模型与套餐结构
- 术语与文案规范
- 5 工具详细流程图
- 关键页面线框草图（首页、工作台、任务中心、样片墙）
- UI/UX 规范草案（含状态与交互规则）
- UX 审核报告（问题清单 + 影响级别 + 修复优先级）
- 设计系统初稿（颜色/字体/间距/组件状态）
- 开发交付清单（Handoff Checklist + QA 验收项）

## 可选交付
- 原型交互稿（可点击）
- 设计资产库（图标/插图/样片占位）
- 事件埋点清单（核心转化漏斗）
- 无障碍检查清单（WCAG 2.2 AA）

## UX 审核报告模板（最小可交付）
- 结构问题：导航、层级、任务流程是否清晰
- 交互问题：按钮语义、反馈、阻断/重试是否明确
- 表单问题：必填/可选、校验、错误提示
- 状态问题：加载/空态/失败态是否齐全
- 可用性问题：是否一屏一主 CTA，是否存在迷路

## 开发交付清单（Handoff Checklist）
- 组件状态：default/hover/focus/active/disabled/loading/error/success
- 交互时序：延迟/动画/轮询/超时
- 文案变体：按钮/提示/错误/空态
- 关键路径埋点：创建任务/试拍/选片/支付
- Edge Cases：网络失败、超时、刷新恢复、批量中断

## 交付验收（必须通过）
- 无遮罩阻塞主操作
- 所有主 CTA 可点击且有反馈
- 工具流程不串场（字段不混用）
- 刷新后任务状态不丢失

## 关键页面线框草图（v1 文本版）

### 1) 首页（工具箱 + 看板 + 样片墙）
```text
+----------------------------------------------------------------------------------+
| Logo | 工具箱 | 素材库 | 任务中心 | 积分中心 | 用户菜单                          |
+----------------------------------------------------------------------------------+
| 左侧工具分组         | Hero价值区（主CTA） | KPI看板 | 近期热销 | 样片主打案例      |
| - 图片工具           |                                                          |
| - 视频工具           | 样片网格（拍同款） + 套餐包入口                           |
+----------------------------------------------------------------------------------+
```

### 2) 工作台（顶部步骤流）
```text
+----------------------------------------------------------------------------------+
| 面包屑：工具箱 > 工坊 > 项目                                                     |
| Step 1 需求素材 -> Step 2 方案确认 -> Step 3 生成执行 -> Step 4 选片分享         |
+----------------------------------------------------------------------------------+
| 当前步骤主操作区（单主CTA）                                                      |
| - 左：参数/输入                                                                   |
| - 右：实时状态与摘要（日志入口默认折叠）                                         |
+----------------------------------------------------------------------------------+
| 结果墙（可筛选：全部/已通过/待筛选/异常）                                        |
+----------------------------------------------------------------------------------+
```

### 3) 任务中心（全局 + 工具维度）
```text
+----------------------------------------------------------------------------------+
| 筛选栏：工具 | 状态 | 时间 | 批次 | 关键字                                       |
+----------------------------------------------------------------------------------+
| 任务表：项目名 | 工具 | 阶段 | 进度 | 更新时间 | 操作（继续/重试/查看）             |
| 批次聚合卡：可展开查看单任务                                                     |
+----------------------------------------------------------------------------------+
```

### 4) 样片墙（运营）
```text
+----------------------------------------------------------------------------------+
| 主打样片（大卡）：行业标签 + 拍同款主CTA                                         |
| 次级样片网格（中卡）：风格标签 + 拍同款                                           |
| 套餐区：价格/交付/内容 + 立即开拍                                                 |
+----------------------------------------------------------------------------------+
```
