# 07 模特人像精修工坊

## 流程
- 批量上传 → 精修方案 → 身份确认 → 单图精修 → 批次交付

## 输入字段
- 主素材组图（必填）
- 风格参考图（可选）
- 替换模特源图（可选）

## 身份确认
- 上传优先
- 未上传则生成候选
- 候选确认后进入批量精修

## 精修方案输出（单图）
- 精修目标
- 局部调整项
- 一致性规则
- 禁止事项

## 批次任务
- 批次任务列表（10张 = 10个单图任务）
- 单图切换逻辑（卡片切换）
- 批次交付状态汇总

## 主 CTA（每步唯一）
- Step1：批量创建单图精修任务
- Step2：确认方案并进入身份确认/精修
- Step3：确认身份（或生成候选）
- Step4：开始精修
- Step5：批次交付确认

## 状态与等待
- 方案生成：骨架占位 + 预计时长
- 身份确认：候选图回填
- 单图精修：逐张回填 + 进度提示

## 异常与边界
- 未上传主素材：阻止创建并提示
- 身份候选生成失败：允许重试
- 未确认身份不可进入精修

## 文案模板（关键节点）
- 成功：精修方案已生成，请确认后进入精修
- 失败：身份候选生成失败，请重试
- 提示：当前为单图任务，方案仅覆盖当前图片

## 状态规范（空态/加载/失败）
- 空态：暂无精修方案，请先生成
- 加载：精修方案生成中，预计 1-2 分钟
- 失败：生成失败，请重试或检查素材
