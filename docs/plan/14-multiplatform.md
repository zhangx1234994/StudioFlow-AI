# 14 多端规划（H5 / 小程序）P2 冻结版

## 1) 移动端最小可用流程（H5）
- 登录 -> 工具箱 -> 创建任务 -> 工作台核心步骤 -> 结果查看/下载。
- 默认仅开放高频动作：创建、查看进度、重试、审核通过。
- 高级操作（批量参数、详细日志）折叠至“更多”。

移动端交互约束：
- 顶部固定主 CTA，底部固定步骤导航。
- 单列布局，减少并排信息块。
- 上传组件支持拍照/相册，状态明确（上传中/完成/失败）。

## 2) 小程序信息架构（冻结）
- 页面 1：工作台看板（最近任务 + 快捷创建）
- 页面 2：工具箱（5 工坊入口）
- 页面 3：任务列表（按工具筛选）
- 页面 4：项目详情（精简版步骤流）
- 页面 5：素材库（我的上传/我的生成）
- 页面 6：账户与积分

## 3) 小程序核心功能优先级（1-2-3级）
- P1（首发必须）：
  - 商品棚拍出图
  - 模特人像精修
  - 任务进度查看与失败重试
- P2（次阶段）：
  - 多角度展品
  - 15 秒短片
  - 样片墙拍同款
- P3（后续）：
  - 转化讲解视频（多脚本）
  - 团队协作管理
  - 充值支付

## 4) 多端一致性规则
- 状态机、进度口径、扣费逻辑必须共用后端唯一真源。
- 文案语义一致（桌面与移动端术语一致）。
- 任务与素材 ID 体系一致，保证跨端无缝恢复。
