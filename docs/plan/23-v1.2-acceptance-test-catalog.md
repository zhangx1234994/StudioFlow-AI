- 积分计费：`AT-BILL-*`

## 1.2 自动化状态
- `Automated`：已有自动化用例并进入 CI。
- `Partial`：仅 API 或仅前端覆盖。
- `Planned`：尚无自动化，仅手工走查。

## 3. 核心 P0 用例定义（执行稿）

## AT-AUTH-001 登录成功链路
- 前置条件：存在可用账号。
- 操作：`POST /api/v1/auth/login`，随后请求 `/api/v1/auth/me`。
- 期望：登录返回 `ok=true`；`/me` 返回 `authenticated=true` 和用户名。

## AT-TASK-001 创建后秒进工作台
- 前置条件：创建参数完整且 OSS URL 可访问。
- 操作：提交创建任务。
- 期望：2 秒内进入目标工作台；不等待后续计划生成完成。

## AT-PI-001 20 镜头完整方案
- 前置条件：`shot_count=20`。
- 操作：点击“生成拍摄方案”。
- 期望：最终 `plan.shots.length=20`；缺项自动补齐，不出现空镜头。

## AT-MR-002 上传模特三模式可用
- 前置条件：已有上传模特图。
- 操作：依次执行“使用上传/精修上传/生成新模特”。
- 期望：每次点击均有状态反馈；至少产出 1 个可确认锚点。

## AT-MR-005 原图比例透传
- 前置条件：批量精修页选择 `原图（默认）`。
- 操作：触发批量生成。
- 期望：请求参数不携带 `image_resolution`；后端使用 `image_aspect_ratio=auto`。

## AT-QV-002 15秒短片参数收敛
- 前置条件：进入 15 秒短片创建页。
- 操作：检查字段可见性。
- 期望：仅展示视频必要字段；不存在图片比例/机位角度等字段。
