# AI摄影棚 v1.2 业务逻辑决策表（逐条细化）

> 目的：把“看起来像体验问题”的内容落到可执行逻辑，减少反复改 UI 但根因不清。

---

## 1. 创建任务与跳转决策表

| 条件 | 判断 | 动作 |
|---|---|---|
| OSS 直传全部成功 | Yes | 调用创建接口并立即跳转工作台 |
| OSS 直传部分失败 | Yes | 标记失败文件，允许重传，未失败文件可继续 |
| 创建接口成功 | Yes | 写入最近任务并导航目标路由 |
| 创建接口失败 | Yes | 显示失败原因，不清空用户已填内容 |

补充规则：
- 创建动作不被“后台大任务”阻塞。
- 创建成功后若批次场景，优先跳 batch 路由。

---

## 2. 模特身份确认决策表（Step2）

| 条件 | 判断 | 动作 |
|---|---|---|
| 有上传模特图 + 模式=use_uploaded | Yes | 直接生成“上传来源候选”并允许确认 |
| 有上传模特图 + 模式=beautify_uploaded | Yes | 基于上传图精修候选 |
| 无上传模特图 + 模式=use/beautify | Yes | 禁用主按钮并提示“先上传或改为生成新模特” |
| 模式=generate_new | Yes | 按参数生成新候选 |
| 用户点击确认锚点 | Yes | identity_status -> confirmed 并允许进入 Step3 |

补充规则：
- 上传/替换后默认 `identity_status=pending`。
- 移除上传图后若无已确认锚点，回退 `pending`。

---

## 3. 模特批量执行分栏决策表（Step3）

| 条件 | 分栏 |
|---|---|
| identity_status != confirmed | 待确认 |
| task_status in {queued,running,rendering} | 执行中 |
| task_status in {failed,error} | 待审核（异常处置） |
| generated_count == 0 且非运行 | 待审核（异常处置） |
| pending_count > 0 or failed_count > 0 | 待审核 |
| 其余 | 可导出 |

补充规则：
- `reviewing` 属于“完成侧”，不可进入 `queued`。
- 执行中列只保留真实运行任务。

---

## 4. 批量等待与超时处置决策表

| 条件 | 动作 |
|---|---|
| running_images > 0 or queued_images > 0 | 开启自动轮询（5秒） |
| running/queued 都为 0 | 关闭自动轮询 |
| 单任务执行超过 3 分钟无变化 | 显示超时提示 + 单任务重试按钮 |
| batch.failed_images > 0 | 开启“仅重跑失败项” |

补充规则：
- 页面必须同时具备自动刷新状态文案和手动刷新按钮。

---

## 5. 比例与分辨率决策表

| 条件 | 请求参数 |
|---|---|
| output_aspect_ratio=original | image_aspect_ratio=auto，且不传 image_resolution |
| output_aspect_ratio!=original | 透传所选比例 + 分辨率 |

补充规则：
- 前端在 original 模式下禁用分辨率控件。
- 后端不允许默认偷偷补 1K。

---

## 6. 扣费逻辑决策表

| 条件 | 动作 |
|---|---|
| 生成前余额不足 | 阻断生成并提示充值/调分 |
| 生成成功 N 个产物 | 扣费 = N * 单价 |
| 生成失败或回退占位 | 不计入成功扣费 |
| 分享样片符合规则 | 发放分享奖励积分 |

---

## 7. 权限决策表

| 角色 | 可见范围 | 写权限 |
|---|---|---|
| admin | 全量项目 | 全量 |
| operator | 指定范围（按配置） | 业务操作 |
| member | 本人项目 | 本人项目 |

补充规则：
- 后端强校验优先，前端隐藏仅作体验层。

---

## 8. 错误处理决策表

| 错误类型 | 用户提示 | 可恢复动作 |
|---|---|---|
| 凭证错误 | 账号或密码错误 | 重新输入 |
| 网络错误 | 网络异常，请重试 | 重试 |
| 模型超时 | 生成超时，可重试 | 重试当前步骤 |
| 权限错误 | 无权限访问该任务 | 返回工具箱 |
| 服务器错误 | 服务异常，请稍后再试 | 重试/联系管理员 |
