# 08 多角度展品工坊

## 流程
- 上传 → 机位控制 → 角度生成 → 结果预览

## 机位控制
- yaw / pitch / distance / focal
- 预设角度组（正面/侧面/背面/高角/低角）
- 一键生成当前角度

## 结果展示
- 逐张回填
- 角度标识

## 主 CTA
- Step1：进入机位控制
- Step2：开始生成当前角度

## 状态与等待
- 角度生成：逐张回填 + 进度提示
- 错误：失败原因 + 重试入口

## 异常与边界
- 未上传主图：阻止进入机位控制
- 机位参数未保存：提示先保存

## 文案模板（关键节点）
- 成功：已生成当前角度，可继续切换角度
- 失败：生成失败，请调整机位参数后重试

## 状态规范（空态/加载/失败）
- 空态：请先上传主图并进入机位控制
- 加载：生成中，预计 1-2 分钟
- 失败：生成失败，请调整机位参数后重试
