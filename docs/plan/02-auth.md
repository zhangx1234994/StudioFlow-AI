# 02 账号体系与认证（P0 冻结版）

## 1) 注册与登录路径（冻结）
- v1 注册入口：邮箱 + 用户名 + 密码（手机号注册后置）。
- v1 登录入口：账号密码（OTP 预留，不开启）。
- 管理员可在用户管理后台创建成员账号（已支持）。

注册校验：
- 用户名唯一，长度 3-32，允许字母/数字/下划线。
- 邮箱唯一，标准邮箱格式。
- 密码最少 8 位，要求字母 + 数字。

## 2) 风控策略（v1 最小集）
- 登录失败计数：10 分钟内连续 5 次失败，账号锁定 15 分钟。
- 异常 IP 频次阈值：同 IP 1 分钟超过 20 次登录尝试则限流。
- 高风险操作（二次确认）：管理员调分、角色变更、冻结账号。
- 安全日志必须保留：`username/ip/user_agent/result/request_id`。

## 3) 会话机制（冻结）
- 默认会话 7 天（可主动退出）。
- 刷新页面保持登录态，失效后自动跳登录页。
- 登录成功后默认跳转 `/app/tools`。

## 4) 组织结构（Workspace）
- v1 逻辑：单 Workspace（`default_workspace`）即可满足当前 SaaS 启动。
- 数据模型预留：`workspace_id` 字段（项目、资产、流水、用户）。
- v1.1 扩展：支持多 Workspace 切换与资源隔离。

## 5) 团队成员邀请与移除（冻结流程）
- v1：管理员在“用户管理”直接创建/禁用成员（不走邮件邀请）。
- v1.1：补充“邀请链接 + 到期时间 + 一次性 token”。
- 移除策略：逻辑禁用账号，不删除历史任务与素材归属。

## 6) 账号信息管理（冻结）
- 用户可修改：显示名、密码（邮箱和用户名默认不可自行改，需管理员处理）。
- 管理员可修改：角色、状态、重置密码、积分调整。
- 变更操作均写审计日志（操作者、目标、变更前后）。

## 7) 账号状态定义（冻结）
- `trial`：试用中，可执行核心流程，额度受限。
- `active`：正常付费或有余额账号。
- `suspended`：违规或风控暂停，禁止新任务。
- `frozen`：长期冻结，仅管理员可恢复。

状态转移：
- 注册后默认 `trial`。
- 首次充值/管理员激活可转 `active`。
- 风控命中转 `suspended`，人工审核后恢复。

## 8) RBAC（与后端一致）
- `admin`：全量权限（含用户管理、财务管理）。
- `operator`：全量业务权限（不含财务管理）。
- `member`：仅本人项目和素材权限。

## 9) 待实施项（代码）
